18Birdies export

  1. Sign in at 18birdies.com/download-account-data (email + password, or phone + SMS code).
  2. Click Request My Data; the browser saves 18Birdies_archive.json into Downloads.
  3. Nothing else: it is picked up from Downloads automatically (18Birdies). Uploading it here works too.

It is the source of truth for strokes. A dated copy is kept as {{ export_dir }}/18Birdies_archive_YYYYMMDD.json; the same file twice changes nothing. The file holds your email, phone and friends list: only the rounds are read.
